# RP5 Weather для Home Assistant

Неофициальная интеграция прогноза и текущих наблюдений [RP5](https://rp5.ru/).
Место выбирается поиском по названию; ключ API не нужен.

![Иконка интеграции](custom_components/rp5_weather/brand/icon.png)

## Возможности

- Поиск населённого пункта с выбором страны, региона и метеостанции.
- Несколько мест как отдельные записи интеграции.
- Weather-сущность с текущей температурой, ветром и условием погоды.
- Прогноз `hourly` с реальными точками источника: сначала 1 час, затем 3 часа.
- Дождь в стандартном поле `precipitation`, снег отдельно в сантиметрах.
- Сенсор времени успешного получения данных; общий кеш для всех сущностей.
- Опрос раз в 60 минут по умолчанию, настройка от 60 до 720 минут.

Минимальная версия Home Assistant: **2026.10.1**. Проверено на HA Core 2026.10.1 / Python 3.14.6.
Интеграция использует внутренние публичные endpoints мобильного сайта; RP5 может изменить их формат или доступность.

## Установка через HACS

1. HACS → меню → **Пользовательские репозитории**.
2. Добавь `https://github.com/konstantinhidirov/ha-rp5-weather`, категория **Интеграция**.
3. Найди **RP5 Weather**, скачай выбранную версию и перезапусти Home Assistant.
4. Настройки → Устройства и службы → Добавить интеграцию → **RP5 Weather**.
5. Введи название, нажми «Далее» и выбери место из списка.

Например, «Астрахань» даёт город, одноимённую деревню и аэропорт Кустодиева.
В выпадающем списке можно фильтровать варианты по региону. «Искать другое название…» возвращает к вводу.
Вместо названия можно вставить полный URL русской страницы RP5.

**Если RP5 уже установлена вручную:** сохрани копию `custom_components/rp5_weather`, затем скачай интеграцию через HACS поверх тех же файлов и перезапусти HA.
Существующую запись в «Устройствах и службах» удалять не нужно: домен, ID места и unique_id сущностей остаются прежними.
Проверь доступность прежних сущностей и `weather.get_forecasts` после перезапуска.

## Ручная установка

Скачай `rp5_weather.zip` из [релизов](https://github.com/konstantinhidirov/ha-rp5-weather/releases),
распакуй его содержимое в `/config/custom_components/rp5_weather` и перезапусти HA.
Либо скопируй из репозитория только каталог `custom_components/rp5_weather`.
Все файлы исполнения находятся внутри этого каталога.

Для удаления используй штатное удаление записей HA и файлов интеграции. Удаление записи может затронуть ID и настройки сущностей;
для обновления это не требуется. Откат версии — установка прежнего релиза поверх файлов и перезапуск HA.

## Настройки

Поле добавления: название города / населённого пункта от 2 до 100 символов или URL страницы `rp5.ru` / `m.rp5.ru`.
После выбора HA проверяет страницу, прогноз и наблюдение и определяет ID и локальное смещение UTC.
Повторное добавление той же точки отклоняется.

В «Настроить» меняется интервал опроса. Перенастройка URL допускает другой адрес той же точки.
Для другого города добавь отдельную запись — так сохраняются стабильные идентификаторы.

## Прогноз и осадки

`weather.get_forecasts` с `type: hourly` возвращает реальные интервалы RP5, без интерполяции.
`daily` и `twice_daily` пока не поддерживаются.

| Поле | Значение |
| --- | --- |
| `precipitation` | Дождь за весь интервал; исходная единица — мм. HA применяет выбранные единицы и стандартное округление. |
| `rp5_snowfall_cm` | Снег за весь интервал в см, без пересчёта в водный эквивалент. |
| `rp5_precipitation_type` | `none`, `rain`, `snow`, `rain_snow`. |
| `rp5_precipitation_interval_hours` | Длительность интервала в часах. |
| `rp5_precipitation_interval_start` | Начало интервала в UTC. |
| `rp5_precipitation_interval_end` | Конец интервала в UTC. |

Столбец RP5 соответствует концу интервала. Если подсказка сообщает в среднем 0.27 мм воды и 0.17 см снега за час
с 19:00 до 22:00, получаются 0.81 мм дождя и 0.51 см снега за три часа. HA может округлить стандартное поле дождя.
При смешанных осадках дождь и снег независимы; при чистом снеге дождь равен нулю.
Неизвестная подсказка не превращается в нулевые осадки. Вероятность осадков не синтезируется.

Ощущаемая температура пропускается, если RP5 не отдаёт её строку. Температура, давление, влажность и ветер сохраняются.

## Текущая погода и ошибки

Текущая температура и ветер берутся из сообщения фактического наблюдения, а не из крупного числа на странице или ближайшего прогноза.
Возраст наблюдения сохраняется; время приблизительное, вычислено из текста «N минут назад».
Наблюдения старше шести часов не выдаются за текущую погоду. Текущие влажность и давление не подменяются значениями прогноза.

Один цикл обновления делает три HTTP-запроса. Чтение прогноза карточками использует кеш и не вызывает дополнительных запросов.
Поиск выполняется только при добавлении, по нажатию «Далее».
Прогноз и наблюдение проверяются независимо. Ошибка HTTP, неверный JSON или несовместимая таблица одной части не скрывают другую исправную часть.
Недоступный прогноз очищается; наблюдение не заменяется прогнозной температурой. При отказе обеих частей обновление считается неуспешным; данные не заменяются нулями.
Атрибуты `forecast_available`, `forecast_error`, `observation_error` показывают состояние частей; `observation_available` показывает наличие свежего наблюдения.
Сенсор «Данные получены» отмечает обновление с хотя бы одной пригодной частью. При добавлении интеграции корректный прогноз обязателен.
HTTP 200 с пустым телом именно у endpoint поиска соответствует отсутствию совпадений.

## Разработка

Код: `custom_components/rp5_weather`. Тесты: `tests`. Архитектура и порядок релиза: [docs/development.md](docs/development.md).
История версий: [CHANGELOG.md](CHANGELOG.md). Лицензия: [MIT](LICENSE).

Push тега `v<manifest.version>` запускает hassfest и тесты, затем автоматически публикует GitHub Release
с архивом `rp5_weather.zip`. Для появления нового релиза в HACS используй «Обновить информацию».

CI запускает HACS validation, hassfest и 56 тестов в контейнере HA Core 2026.10.1.
Официальная проверка HACS требует описание репозитория, включённые issues и topics на GitHub;
рекомендуемые topics: `home-assistant`, `hacs`, `weather`, `rp5`, `custom-integration`.

Локальные тесты парсера и поиска без HA:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m unittest discover -s tests -v
```

Тесты формы добавления требуют установленный HA и в этом режиме будут пропущены.
Все тесты с HA:

```sh
docker run --rm --entrypoint python -v "$PWD:/repo:ro" -w /repo \
  ghcr.io/home-assistant/home-assistant:2026.10.1 -m unittest discover -s tests -v
```

Проверка живого источника (системный HTTP/HTTPS proxy учитывается только CLI):

```sh
.venv/bin/python probe.py 'https://rp5.ru/Погода_в_Астрахани,_им._Б._М._Кустодиева_(аэропорт)' --output sample.json
```
